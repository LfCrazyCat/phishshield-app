# phishshield-app
Cybersecurity learning app built with Expo and LM Studio (Overførte hele prosjektet til et nytt prosjekt, for å få mer oversikt)

PhishShield: en mobilapplikasjon utviklet som et lærings- og demonstrasjonsprosjekt for privatpersoner.

Prosjektet er laget for å vise hvordan enkle, bevisste teknologiske valg kan brukes til å bygge et opplæringsverktøy med lav kompleksitet, forutsigbarhet og redusert angrepsflate. Applikasjonen er bygget uten backend-tjenester, uten brukerinnlogging og uten datainnsamling og fungerer fullt ut offline.


Målet med PhishShield er å hjelpe brukere med å:
* forstå hvordan phishing fungerer i praksis  
* gjenkjenne vanlige mønstre og teknikker  
* ta bedre beslutninger når de mottar mistenkelige meldinger  

Samtidig er prosjektet brukt til å utforske hvordan sikkerhet, arkitektur og personvern kan ivaretas gjennom bevisste fravalg og enkel design.
